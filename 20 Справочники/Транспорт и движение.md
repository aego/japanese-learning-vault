# Транспорт и движение

> [!note] Кандзи — справочная орфография
> Основное написание для повторения — кана. Активный набор подтверждённых кандзи находится в [[20 Справочники/Кандзи — изученные]].

## Движение

| Японский | Значение | Короткий пример |
|---|---|---|
| いきます（行きます） | идти, ехать | がっこうへ いきます。 |
| きます（来ます） | приходить, приезжать | にほんへ きます。 |
| かえります（帰ります） | возвращаться | うちへ かえります。 |
| あるいて（歩いて） | пешком | あるいて いきます。 |

## Места

| Японский | Значение | Короткий пример |
|---|---|---|
| がっこう（学校） | школа | がっこうへ いきます。 |
| スーパー | супермаркет | スーパーへ いきます。 |
| えき（駅） | станция, вокзал | えきへ いきます。 |

## Транспорт

| Японский | Значение |
|---|---|
| ひこうき（飛行機） | самолёт |
| ふね（船） | корабль |
| でんしゃ（電車） | поезд, электричка |
| ちかてつ（地下鉄） | метро |
| しんかんせん（新幹線） | синкансэн, скоростной поезд |
| バス | автобус |
| タクシー | такси |
| じてんしゃ（自転車） | велосипед |

Транспорт обозначается частицей `で`:

`でんしゃで いきます。` — Еду на поезде.

Исключение по форме: `あるいて いきます` — идти пешком; частица `で` не нужна.

## На станции

| Японский | Значение |
|---|---|
| ～ばんせん（～番線） | платформа / путь №… |
| つぎの（次の） | следующий |
| ふつう（普通） | обычный поезд со всеми остановками |
| きゅうこう（急行） | поезд-экспресс; express |
| とっきゅう（特急） | скорый поезд по переводу учебника; limited express |

## Важные различия

- `へ` показывает направление: `えきへ いきます` — ехать на станцию.
- `で` показывает транспорт: `バスで いきます` — ехать на автобусе.
- Японская иерархия: `ふつう` → `きゅうこう` → `とっきゅう`.
- Точные международные названия: local → express → limited express; `とっきゅう` обычно выше и быстрее `きゅうこう`.
- В русском переводе учебника: обычный поезд → поезд-экспресс → скорый поезд. Русские слова «экспресс» и «скорый» сами по себе плохо передают японскую иерархию, поэтому надёжнее запоминать японские категории.
