# Люди и отношения

> [!note] Кандзи — справочная орфография
> При повторении ориентироваться на кану. `人` и `車` уже подтверждены по фотографии; статус остальных знаков проверять в [[20 Справочники/Кандзи — изученные]].

## Урок 5

| Японский | Значение | Короткий пример |
|---|---|---|
| ひと（人） | человек | あの ひとは だれですか。 |
| ともだち（友達） | друг | ともだちと いきます。 |
| かれ（彼） | он; молодой человек | かれは せんせいです。 |
| かのじょ（彼女） | она; девушка | かのじょは がくせいです。 |
| かぞく（家族） | семья | かぞくと いきます。 |
| ひとりで（一人で） | один, самостоятельно | ひとりで がっこうへ いきます。 |

## Важное различие

- `ひとりで` описывает действие без спутника: «один / самостоятельно».
- Спутник обозначается через `と`: `ともだちと いきます` — иду / еду с другом.
