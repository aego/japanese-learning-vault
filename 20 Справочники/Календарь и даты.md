# Календарь и даты

> [!note] Кандзи — справочная орфография
> При повторении сначала воспроизводить чтение каной. Числовые кандзи и `日／月` подтверждены по фотографиям, остальные знаки здесь даны только для справки.

## Недели, месяцы и годы

| Период | Прошлый | Этот | Следующий |
|---|---|---|---|
| неделя | せんしゅう（先週） | こんしゅう（今週） | らいしゅう（来週） |
| месяц | せんげつ（先月） | こんげつ（今月） | らいげつ（来月） |
| год | きょねん（去年） | ことし（今年） | らいねん（来年） |

## Месяцы

- `～がつ（～月）` — ...-й месяц: `しちがつ` — июль.
- `なんがつ（何月）` — какой месяц.

## Особые чтения дат

| Дата / длительность | Чтение |
|---|---|
| 1-е число | ついたち（一日） |
| 2-е число / два дня | ふつか（二日） |
| 3-е число / три дня | みっか（三日） |
| 4-е число / четыре дня | よっか（四日） |
| 5-е число / пять дней | いつか（五日） |
| 6-е число / шесть дней | むいか（六日） |
| 7-е число / семь дней | なのか（七日） |
| 8-е число / восемь дней | ようか（八日） |
| 9-е число / девять дней | ここのか（九日） |
| 10-е число / десять дней | とおか（十日） |
| 14-е число / четырнадцать дней | じゅうよっか（十四日） |
| 20-е число / двадцать дней | はつか（二十日） |
| 24-е число / двадцать четыре дня | にじゅうよっか（二十四日） |

Для остальных дат используется `число + にち`: например, `じゅういちにち` — 11-е число.

- `なんにち（何日）` — какое число; сколько дней.
- `いつ` — когда.
- `たんじょうび（誕生日）` — день рождения.

## Важные различия

- `よっか` — 4-е число, `ようか` — 8-е число.
- `らいげつ` — следующий месяц, `らいねん` — следующий год.
- `じゅうよっか` и `にじゅうよっか` имеют особое чтение `よっか`.
