# База японского языка

Obsidian-хранилище со справочными материалами для изучения японского языка по курсу *Minna no Nihongo I* и инструкциями для работы с ИИ-преподавателем.

## Что публикуется

- тематические справочники по лексике, кане, числам, датам и грамматическим конструкциям;
- проектные инструкции для ИИ-ассистента;
- вспомогательные материалы, не содержащие историю обучения конкретного ученика.

## Что остаётся локальным

`.gitignore` исключает личный прогресс, журналы упражнений и ошибок, архив диалогов, подтверждённый набор изученных кандзи, ежедневные заметки, фото тетради и локальное состояние Obsidian.

Заметки уроков сейчас также остаются локальными, поскольку учебный материал в них смешан с персональным журналом занятий. Перед их публикацией следует вынести журналы в отдельную приватную папку и обезличить поля статуса.

## Использование

Откройте каталог как хранилище Obsidian. Правила для ИИ-ассистента находятся в `AGENTS.md`, а подробный порядок ведения базы — в `LLM — инструкция по работе с хранилищем.md`.
